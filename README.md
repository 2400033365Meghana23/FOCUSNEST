## 🌸 About the Project

**FOCUSNEST** is a **multi-page React productivity application** designed especially for students.  
It helps users **organize tasks, write notes, and stay focused** using a built-in Pomodoro timer — all in a calm, minimal interface.

This project was built step-by-step starting from **HTML, CSS, and JavaScript**, and later upgraded into a **React application** with routing and advanced UI features.

---

## ✨ Key Features

🌿 **Multi-Page Navigation** (React Router)  
📝 **Task Management** (Add & manage daily tasks)  
📌 **Notes Section** (Save important notes)  
⏳ **Pomodoro Focus Timer** (25-minute focus sessions)  
🌗 **Dark / Light Theme Toggle**  
🎨 **Clean, aesthetic UI with animations**  
💾 **LocalStorage support** (data persists on refresh)
